# ПТ: персональный терминал

Полностью самодельный ретро-компьютер: **собственный процессор, операционная система, виртуальная машина,
язык программирования и пользовательское ПО**, без зависимости от корпоративных платформ.
Проект творческий и научный. Код пишется вместе с ИИ-агентом, но каждый шаг разбирается и проверяется
автором: принципиально, чтобы человек понимал свою систему изнутри.

Семейство устройств на общей платформе:

| Устройство | Роль |
|------------|------|
| **ПТ** | персональный компьютер в духе старых ПК: загрузка с дискет, программы с CD, тяжёлое с DVD |
| **КПТ** | компактный сенсорный терминал, лёгкая оболочка, пульт управления роботом, та же ОС в облегчённом профиле |
| **Робот** | отдельная экосистема: рефлексы на общем ядре, «мозг» на отдельном модуле, связь по общему протоколу |

## Что уже работает

Всё ниже проверяется автоматически при каждом commit (см. «Проверки»).

- **Процессор.** Собственное ядро RISC-V RV32IMC на Verilog, режим M, прерывания и исключения по стандарту.
  Проверено в симуляторе: на нём работает настоящая ОС. На плате пока не запускалось.
- **SoC.** Ядро, ОЗУ, UART (регистры как у 16550), таймер (адреса как у CLINT).
- **Загрузка.** Boot ROM читает системную дискету, проверяет заголовок и CRC и запускает ядро.
- **ОС.** Ядро с прерываниями и таймером, командная строка, файловая система PTFS (чтение), запуск программ,
  ввод с консоли (с русскими буквами), время и пауза.
- **Виртуальная машина.** Стековая, с проверкой любых обращений к памяти: сломанная программа останавливается,
  система продолжает работать. Одинаковая на ПК и в ядре.
- **Язык «Слог».** Питоноподобный, все слова и имена по-русски: функции, рекурсия, списки, строки (Юникод),
  циклы, модули, вывод типов, библиотеки.
- **Инструменты.** Ассемблер, компилятор Слога, сборщики образов дискет и файловой системы.

## Пример

```
# examples/stroki.sl
функция обратить(с):
    р = ""
    для к в диапазон(длина(с)):
        р = из_кода(с[к]) + р
    вернуть р

печать(обратить("привет"))        # тевирп
```

Сеанс в командной строке ПТ (так же он проходит в автоматической проверке):

```
> ls
hello.ptb       166 bytes  program
privet.ptb      513 bytes  program
readme.txt       54 bytes  text
> run privet.ptb
Привет, мир!
```

## Как попробовать на обычном компьютере

Нужны Python 3 и компилятор C. Платы и RISC-V компилятор для этого не нужны.

```
gcc -O2 -o out/host vm/host.c vm/vmio.c vm/vm.c                # запускатель программ на ПК
python3 tools/slog.py examples/privet.sl out/privet.pta        # Слог -> ассемблер
python3 tools/ptasm.py out/privet.pta out/privet.ptb           # ассемблер -> байткод
./out/host out/privet.ptb                                      # запуск
```

Полная система (ядро, загрузка с «дискеты», шелл) собирается и проверяется в облаке через GitHub Actions:
компилятор `riscv64-unknown-elf-gcc` и эмулятор QEMU ставятся там автоматически.

## Устройство репозитория

| Папка | Что там |
|-------|---------|
| `rtl/` | Verilog: ядро процессора (`cpu.v`), SoC (`soc.v`), UART, таймер |
| `sim/` | тесты железа: тестбенчи, самотест процессора на C, запуск шелла на нашем ядре |
| `boot/` | boot ROM: читает системный носитель, проверяет CRC, запускает ядро |
| `kernel/` | ядро ОС: ловушки, таймер, консоль, шелл, файловая система PTFS |
| `vm/` | виртуальная машина, ввод-вывод для программ, запускатель для ПК, их тесты |
| `tools/` | ассемблер, компилятор Слога (по модулям), сборщики образов, тесты компилятора |
| `lib/` | библиотеки на Слоге: строки, списки, математика, случайные числа |
| `examples/` | примеры программ на Слоге и ассемблере |
| `docs/` | документация (см. ниже) |
| `.github/workflows/` | автоматические проверки |

## Проверки

Три независимые проверки запускаются при каждом commit (вкладка Actions):

| Проверка | Что проверяет |
|----------|---------------|
| **vm** | виртуальная машина, ассемблер, компилятор Слога (около 290 проверок языка), ввод UTF-8, файловая система, арифметика времени ядра, сборка под RISC-V |
| **build** | сборка ядра и boot ROM для RISC-V, образы дискет, загрузка в QEMU и запуск программ с «дискеты B» |
| **rtl** | процессор на Verilog в симуляторе: тесты UART и таймера, самотест ядра, настоящая ОС с шеллом на нашем процессоре |

Компилятор и библиотеки дополнительно проверялись намеренными поломками («мутациями»): если в код внести
ошибку, тесты обязаны её заметить.

## Состояние и ограничения

- Процессор проверен только в симуляторе. Проекта под Quartus и запуска на плате (EP4CE6E22) пока нет.
- Дискеты и CD в этой версии «эмулируются» областью памяти; драйверов настоящих приводов пока нет.
- Файловая система PTFS пока только для чтения, до 15 файлов на носитель.
- В языке только 32-битные целые: дробных чисел, словарей и списков с изменяемой длиной ещё нет.
- Память программы в ядре небольшая (буфер программы 4 КБ, память ВМ 2 КБ): рассчитано на плату с внешней памятью.
- Лицензия пока не выбрана.
