# ПТ: персональный терминал

Самодельное семейство устройств на общей платформе: **ПТ** (персональный компьютер),
**КПТ** (компактный сенсорный терминал) и **робот**. Цель проекта: полностью своё
железо, ОС, ПО и язык, без зависимости от корпоративных платформ.
Проект творческий и научный, пишется вайбкодингом (агент Claude) с разбором кода.

## Архитектура

- **ISA:** RISC-V RV32 (I, затем M и C) + Zicsr, режим M. S-режим, MMU и RV64 позже.
- **Ядро процессора:** собственное, на Verilog (`rtl/cpu.v`), многотактовое.
- **SoC:** ядро + ОЗУ + UART (регистры как у 16550) + таймер (адреса как у CLINT в QEMU).
- **ПТ:** загрузка с дискеты A, программы с CD-ROM, тяжёлое с DVD. До 2 флоппи,
  1-2 CD-ROM и 1 пишущий CD/DVD (PATA). Сначала текст, позже framebuffer.
- **КПТ:** та же ОС в лёгком профиле, загрузка из флеш-памяти.
- **Робот:** отдельная экосистема. Рефлексы на общем ядре, «мозг» на отдельном модуле.
- **Байткод и протокол связи:** общие для всех устройств, не зависят от железа.
  Радио с шифрованием (X25519 + ChaCha20-Poly1305) и провод.
- **Платы:** сейчас EP4CE6E22 (Cyclone IV) только для обкатки, боевая будет мощнее.

## Карта репозитория

| Путь | Что там |
|------|---------|
| `boot/` | boot ROM: читает носитель, проверяет CRC, грузит ядро |
| `kernel/` | ядро ОС: ловушки, таймер, консоль, шелл |
| `rtl/` | Verilog: `cpu.v` (ядро), `soc.v` (система), `uart.v`, `clint.v` |
| `sim/` | тесты железа: тестбенчи и самотест на C |
| `tools/` | `mkmedia.py` (образы носителей), `bin2hex.py` |
| `docs/` | `ARCHITECTURE.md`, `MEDIA.md` (формат заголовка носителя) |

## Как проверить, что всё работает

Каждый commit запускает две проверки во вкладке Actions:
- **build:** сборка ядра и boot ROM, образ дискеты, загрузка в QEMU.
- **rtl:** тесты UART и таймера, самотест нашего ядра в симуляторе, шелл на нашем ядре.

Зелёные галочки значит, что всё в порядке.
