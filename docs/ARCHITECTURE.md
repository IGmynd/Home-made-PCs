# ПТ: архитектура (v0.1)

Семейство устройств на одной платформе: ПТ, КПТ, робот.

## Общее
- ISA: RISC-V RV32IMC + Zicsr, режимы M и U. S-режим, MMU, RV64 позже.
- Байткод и VM: общие для всех устройств, не зависят от железа.
- Протокол связи: один пакетный, два канала (радио с шифрованием и провод).
- Шифрование: готовое открытое (X25519 + ChaCha20-Poly1305), своё не пишем.
- HDL: чистый Verilog без вендорных блоков, шина Wishbone.
- Первая плата: EP4CE6E22 (Cyclone IV), только для обкатки.

## ПТ (персональный компьютер)
- Загрузка: boot ROM -> дискета A -> ядро -> шелл.
- Дискета A: системная (ядро, драйверы, шелл).
- Дискета B: пользовательская (настройки, файлы).
- CD-ROM: программы и утилиты. Обязателен для работы.
- DVD: тяжёлое и ситуативное. Опционален.
- Приводы: 2 флоппи, 1-2 CD-ROM, 1 пишущий CD/DVD (PATA).
- Сначала текстовый режим, позже framebuffer.
- Кооперативная многозадачность.

## КПТ (компактный)
- Сенсорная оболочка, пульт робота.
- Та же ОС, облегчённый профиль, загрузка из флеш-памяти.

## Робот
- Отдельная экосистема. Рефлексы на общем ядре.
- Мозг (ИИ) на отдельном мощном модуле, связь по общему протоколу.
- Данные принимает по связи и с дисков.

## Разработка
- Сначала кросс-компиляция (GitHub Actions + QEMU).
- Затем self-hosting на ПТ.
