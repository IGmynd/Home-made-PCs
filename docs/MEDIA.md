# Заголовок носителя v1

Лежит в начале ЛЮБОГО носителя (LBA 0, первые 512 байт).
На CD это системная область ISO 9660, она свободна.
Порядок байтов: little-endian.

| Смещение | Размер | Поле |
|----------|--------|------|
| 0x00 | 4 | magic "PTMD" |
| 0x04 | 2 | версия формата (1) |
| 0x06 | 1 | класс: 1=системный, 2=данные, 3=программы, 4=тяжёлое |
| 0x07 | 1 | флаги (бит0: загрузочный) |
| 0x08 | 16 | метка, ASCII, добивается нулями |
| 0x18 | 4 | id тома |
| 0x1C | 1 | минимальный профиль: 1=КПТ, 2=ПТ |
| 0x1D | 3 | резерв (0) |
| 0x20 | 4 | загрузка: LBA начала образа |
| 0x24 | 4 | загрузка: число секторов |
| 0x28 | 4 | загрузка: адрес в ОЗУ |
| 0x2C | 4 | загрузка: точка входа |
| 0x30 | 4 | CRC32 образа |
| 0x34 | 4 | всего блоков на носителе |
| 0x38 | 0x1C4 | резерв (0) |
| 0x1FC | 4 | CRC32 заголовка (байты 0x00-0x1FB) |

Правила:
- Заголовок с неверным CRC считается повреждённым, носитель отвергается.
- Boot ROM берёт только класс 1 с флагом загрузочного.
- Программа указывает в своём заголовке, какие классы носителей ей нужны.
