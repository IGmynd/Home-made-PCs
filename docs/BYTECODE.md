# Байткод ПТ (PTBC v1)

Стековая машина, ячейки 32 бита со знаком, порядок байтов little-endian.
Одна программа работает на ПТ, КПТ и роботе: различаются только системные вызовы.

## Файл программы (.ptb)

| Смещение | Размер | Поле |
|----------|--------|------|
| 0 | 4 | magic "PTBC" |
| 4 | 2 | версия (1) |
| 6 | 2 | флаги (0) |
| 8 | 4 | длина кода |
| 12 | 4 | длина данных |
| 16 | | код, затем данные |

Данные копируются в память с адреса 0, остальная память обнуляется.
Код отделён от данных (программа не может изменить свой код). Выполнение начинается с байта 0 кода.

## Команды

Обозначения: ( до -- после ), правая сторона это вершина стека.

| Код | Имя | Операнд | Действие |
|-----|-----|---------|----------|
| 00 | halt | | завершить |
| 01 | push8 | s8 | ( -- n ) |
| 02 | push32 | i32 | ( -- n ) |
| 03 | dup | | ( a -- a a ) |
| 04 | drop | | ( a -- ) |
| 05 | swap | | ( a b -- b a ) |
| 06 | over | | ( a b -- a b a ) |
| 10-14 | add sub mul div mod | | ( a b -- a?b ), знаковые, переполнение заворачивается |
| 15-17 | and or xor | | побитовые |
| 18-1A | shl shr sar | | сдвиг a на b бит (b берётся по модулю 32); shr логический, sar арифметический |
| 1B-1C | neg not | | ( a -- -a ), ( a -- ~a ) |
| 20-25 | eq ne lt le gt ge | | ( a b -- 0 или 1 ), знаковое сравнение |
| 30 | ld32 | | ( addr -- v ) |
| 31 | st32 | | ( v addr -- ) |
| 32 | ld8 | | ( addr -- v ), без знака |
| 33 | st8 | | ( v addr -- ), младший байт |
| 40 | jmp | u32 | безусловный переход (абсолютный адрес в коде) |
| 41 | jz | u32 | ( c -- ) переход, если c == 0 |
| 42 | jnz | u32 | ( c -- ) переход, если c != 0 |
| 43 | call | u32 | вызов подпрограммы |
| 44 | ret | | возврат |
| 50 | sys | u8 | системный вызов |

Деление на ноль это ошибка. `-2147483648 / -1` даёт `-2147483648`, остаток 0.

## Системные вызовы

| № | Имя | Действие |
|---|-----|----------|
| 1 | putc | ( c -- ) вывести символ |
| 2 | getc | ( -- c ) прочитать символ, -1 если нет |

Остальные номера зарезервированы под ОС, носители, робота и связь.

## Ошибки

ВМ никогда не падает: любое нарушение (стек, память, переход, неизвестная команда,
лимит шагов) возвращается кодом ошибки, программа просто останавливается.

## Что планируется

Локальные переменные, вызовы с параметрами, 64-битные ячейки, больше системных вызовов.
Это потребует версии 2 формата, поэтому в заголовке есть поле версии.
