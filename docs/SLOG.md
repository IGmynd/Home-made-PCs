# Слог: язык программирования для ПТ

Питоноподобный язык, в котором **все слова языка и имена по-русски**. Латинские буквы в именах запрещены.
Программа компилируется в байткод ПТ (см. [BYTECODE.md](BYTECODE.md)) и работает на ПТ, КПТ и роботе.
Файлы с программами называются `*.sl` (расширение латинское: консоль пока передаёт только ASCII в именах файлов).

## Быстрый старт

```
функция факт(н):
    если н <= 1:
        вернуть 1
    вернуть н * факт(н - 1)

печать("факториал 10 =", факт(10))

данные = [5, 3, 9, 1]
для х в данные:
    печать(х)
```

```
python3 tools/slog.py примеры.sl out/пример.pta        # Слог -> ассемблер
python3 tools/ptasm.py out/пример.pta out/пример.ptb   # ассемблер -> байткод
./out/host out/пример.ptb                              # запуск на ПК
```

Готовый `.ptb` кладётся на дискету B (`tools/mkfs.py`) и запускается в шелле ПТ командой `run имя.ptb`.
Примеры лежат в `examples/`: `privet`, `fakt`, `prostye`, `sort`, `sito`, `stroki`, `echo`, `chisla`, `vremya`,
`kubik`.

## Общие правила

- Блоки задаются отступом из **пробелов** (табуляция запрещена) после строки с `:`.
- Короткий блок можно писать в той же строке: `если х > 0: печать(х)`.
- Комментарий начинается с `#`. Длинные вызовы и списки можно переносить внутри скобок.
- Имена: русские буквы, цифры и `_`, не с цифры (`счёт`, `сумма_1`). Нельзя называть переменные и функции
  словами языка.
- Команды выполняются сверху вниз; функции можно вызывать до их определения.

### Слова языка

| Слово | Смысл |
|-------|-------|
| `если` `иначе_если` `иначе` | условие |
| `пока` `прервать` `продолжить` | цикл по условию |
| `для` ... `в` | цикл по числам или по элементам (`в` особое слово только в заголовке `для`) |
| `функция` `вернуть` | функции |
| `глобальная` | изменять глобальную переменную внутри функции |
| `пропуск` | пустая команда (пустых блоков не бывает) |
| `и` `или` `не` | логика (`и`, `или` вычисляются лениво) |
| `истина` `ложь` | 1 и 0 |
| `подключить` | подключить модуль |

Кроме того зарезервированы имена `печать` и `диапазон`. Имена встроенных функций (`число`, `строка` и так далее)
занять **можно**: переменная `число` и вызов `число(...)` различаются скобками, а своя функция с таким именем
заменяет встроенную.

## Числа

Только **целые числа 32 бита со знаком** (от -2147483648 до 2147483647); переполнение заворачивается.
Дробных чисел пока нет.

| Запись | Пример | Значение |
|--------|--------|----------|
| десятичное | `255` | 255 |
| шестнадцатеричное, префикс `0ш` | `0шЕЕ` | 255 |
| двоичное, префикс `0д` | `0д1010` | 10 |

В шестнадцатеричных числах цифры 10-15 пишутся русскими буквами **А Б В Г Д Е** (любой регистр),
латинские буквы запрещены. Число до 8 цифр, `0шЕЕЕЕЕЕЕЕ` это -1.

## Строки

```
с = "привет"
т = с + ", мир!"                  # склейка
печать(т, длина(т), т[0])         # привет, мир! 12 1087
если с == "привет": ...           # сравнение
если "а" < "б": ...               # и по порядку
печать("число: " + строка(42))    # число в строку
```

Строка это блок **кодов символов Юникода**, как список. Поэтому `длина("привет")` равно 6, а не 12:
считаются буквы, а не байты. `с[и]` даёт код буквы, `из_кода(к)` делает строку из одной буквы, `для х в с:`
обходит буквы. При печати коды превращаются в UTF-8 (русские буквы, знак евро и эмодзи выводятся правильно).

Экранирование в литералах: `\н` перевод строки, `\т` табуляция, `\"` кавычка, `\\` обратная косая.

- Строки можно складывать (`+`) и сравнивать (`==`, `!=`, `<`, `<=`, `>`, `>=`, по кодам символов). Остальные
  операции со строками (`-`, `*` и так далее) запрещены.
- Каждая склейка создаёт новую строку. Строки не освобождаются сами, см. «Память».
- Строку не стоит менять через индекс (`с[0] = ...`): литералы с одинаковым текстом разделяют одну область.

## Типы

У значения один из двух типов: **число** (в том числе список) или **строка**. Компилятор определяет типы сам:
по присваиваниям, по вызовам функций (так узнаётся тип параметра) и по `вернуть`. Это нужно, чтобы `печать(с)`
знала, как печатать значение.

- Переменная, параметр или результат функции не могут быть то числом, то строкой: ошибка компиляции.
- Строку нельзя использовать как условие, индекс или аргумент арифметики.
- Тип элементов списка компилятор не отличает. Чтобы обработать элемент как строку, нужна пометка:
  `печать(строкой(слова[0]))`. Эта запись ничего не делает при работе, только сообщает компилятору тип.
- Функция, возвращающая строку, должна везде возвращать строку (без `вернуть` в конце она вернёт число 0).

## Операции

От низшего приоритета к высшему:

| Операции | Заметки |
|----------|---------|
| `или` | ленивое |
| `и` | ленивое |
| `не` | |
| `==` `!=` `<` `<=` `>` `>=` | цепочки `a < b < c` запрещены, пишите `a < b и b < c` |
| `\|` | побитовое ИЛИ |
| `^` | исключающее ИЛИ |
| `&` | побитовое И |
| `<<` `>>` | `>>` арифметический (знак сохраняется) |
| `+` `-` | |
| `*` `//` `%` | |
| унарные `-` `~` | |
| индекс `а[и]`, вызов `ф(...)` | высший |

Составное присваивание: `+=` `-=` `*=` `//=` `%=` (в том числе для элементов списка).
Деление `//` и остаток `%` **обрезают к нулю** (в Питоне округляют вниз): `-7 // 2` это `-3`.

## Переменные и присваивание

- Присваивание создаёт переменную: `икс = 5`.
- Переменные верхнего уровня глобальные. Внутри функции присваивание создаёт **локальную** переменную, а читать
  можно и глобальные. Чтобы изменить глобальную, объявите `глобальная имя`.
- Читать переменную, которой нигде нет, нельзя (ошибка компиляции). Локальные при входе в функцию равны 0.
- Несколько значений сразу: `а, б = б, а` (обмен), `х, у = 3, 4`. Сначала считаются все правые части, потом
  идёт присваивание, поэтому обмен работает. Слева могут стоять имена и элементы списков.

## Функции

```
функция имя(параметр1, параметр2):
    ...
    вернуть значение
```

- Определяются только на верхнем уровне.
- Возвращают число или строку; без `вернуть` (или с пустым `вернуть`) результат число 0.
- Рекурсия работает. Глубина ограничена 128 вложенными вызовами и памятью программы.
- До 255 локальных переменных (с параметрами) в одной функции.

## Списки

```
а = [10, 20, 30]         # литерал
б = список(5)            # пять нулей
а[1] = 50                # запись; можно и а[1] += 2
печать(а[0], длина(а))   # чтение и длина
м = [[1, 2], [3, 4]]     # списки в списках: м[1][0] это 3
```

- Размер списка **фиксирован** при создании (до 16 777 216 элементов).
- Список это адрес блока памяти. При передаче в функцию копии не делается: функция видит и может менять
  тот же список. `печать(список)` печатает этот адрес, а не элементы.
- Индекс проверяется: выход за границы останавливает программу (ошибка ВМ `-13`).

## Условия и циклы

```
если х < 0:
    печать("минус")
иначе_если х == 0:
    печать("ноль")
иначе:
    печать("плюс")

пока условие:                   # по условию
для к в диапазон(5):            # 0 1 2 3 4
для к в диапазон(2, 11, 3):     # 2 5 8
для к в диапазон(5, 0, -2):     # 5 3 1
для х в [4, 5, 6]:              # по элементам списка или строки
```

- Шаг в `диапазон` обязан быть числом-константой, не нулём.
- Изменение переменной цикла внутри тела не влияет на ход цикла.
- `прервать` выходит из цикла, `продолжить` переходит к следующему шагу.

## Встроенные команды и функции

| Имя | Действие |
|-----|----------|
| `печать(a, b, ...)` | вывести значения через пробел и перевод строки; строки и числа. Это команда, внутри выражения её использовать нельзя |
| `символ(код)` | вывести один байт, вернуть 0 |
| `ввод_символ()` | прочитать байт с консоли без ожидания, -1 если ничего нет |
| `ввод_строка()` | прочитать строку с консоли (ждёт Enter) и вернуть её как строку; русские буквы и эмодзи работают, конец ввода даёт пустую строку |
| `список(n)` | новый список из n нулей |
| `длина(список или строка)` | число элементов или букв |
| `строка(число)` | число в строку: `строка(-12)` это `"-12"` |
| `число(строка)` | строка в число: читает необязательный минус и цифры, остальное игнорирует, пустое это 0 |
| `срез(строка, от, до)` | часть строки, `до` не включается; границы подрезаются |
| `из_кода(код)` | строка из одной буквы с таким кодом Юникода |
| `строкой(значение)` | сообщает компилятору, что значение (например элемент списка) это строка |
| `время()` | миллисекунды с запуска программы (на ПТ с запуска системы) |
| `пауза(мс)` | подождать столько миллисекунд; для нуля и отрицательных ничего не делает |
| `выделить(байты)` | выделить обнулённую память из кучи, вернуть адрес |
| `читать(адрес)` `писать(адрес, значение)` | слово (4 байта) в памяти программы |
| `читать_байт(адрес)` `писать_байт(адрес, значение)` | один байт в памяти |
| `память_метка()` | запомнить, сколько кучи занято; вернуть метку |
| `память_сбросить(метка)` | освободить всю память, выделенную после метки |

## Память

Память, которую занимают строки и списки, сама не освобождается. Для долгих программ (например шелла) есть метки:

```
пока истина:
    м = память_метка()          # запомнили
    команда = ввод_строка()
    ... разбор, строки, списки ...
    память_сбросить(м)          # всё созданное после метки освобождено
```

Значения, созданные после метки, после сброса недействительны: их нельзя хранить дальше. ВМ при этом остаётся
безопасной: ошибочная метка даёт ошибку, а не порчу памяти. Размер памяти программы определяется владельцем ВМ.

## Модули и библиотеки

```
подключить "stroki"     # ищется в папке lib/, затем рядом с программой
подключить "spiski"
```

- `подключить` допустимо только на верхнем уровне. Команды модуля выполняются в месте подключения, функции и
  переменные общие для всей программы.
- Каждый модуль подключается один раз (повторы и круговые подключения безопасны).
- Стандартная библиотека (`lib/`) ищется первой: файл рядом с программой не может её подменить.
- **Лишнее выбрасывается:** из модулей в программу попадают только те функции, до которых можно дойти вызовами.
  Свои функции программы остаются всегда. Поэтому большие библиотеки ничего не стоят, пока их не используешь.
- Ошибка внутри модуля называет файл: `stroki.sl, строка 12: ...`.
- Две функции с одним именем (в программе и в модуле или в двух модулях) это ошибка.

### `stroki`: строки

| Функция | Действие |
|---------|----------|
| `начинается_с(с, префикс)` | 1 или 0 |
| `заканчивается_на(с, суффикс)` | 1 или 0 |
| `найти(с, часть)` | номер первого вхождения или -1 |
| `содержит(с, часть)` | 1 или 0 |
| `обрезать(с)` | убрать пробелы по краям |
| `число_слов(с)` | сколько слов (разделитель пробел) |
| `слова(с)` | разбить по пробелам: список строк (читать элемент как `строкой(п[0])`) |
| `соединить(части, разделитель)` | склеить список строк |
| `повторить(с, н)` | строка, повторённая н раз |
| `обратить(с)` | перевернуть строку |
| `в_верхний(с)` `в_нижний(с)` | регистр, русские и латинские буквы |

### `spiski`: списки чисел

`сумма(а)`, `наибольшее(а)`, `наименьшее(а)` (список не пустой), `содержит_число(а, х)`, `копия(а)`,
`перевернуть(а)` и `сортировать(а)` (оба на месте, возвращают 0).

### `matem`: математика

`абс(х)`, `мин(а, б)`, `макс(а, б)`, `знак(х)`, `степень(основание, показатель)` (для отрицательной степени 0),
`нод(а, б)`, `корень(х)` (целая часть, для чисел до нуля 0), `по_модулю(а, м)` (остаток от 0 до м-1),
`ограничить(х, от, до)`.

### `sluchai`: случайные числа

`посеять(х)`, `случайное(н)` (от 0 до н-1; для н вне 1..1073741824 даёт 0), `случайное_от(от, до)`
(включительно). Простой линейный генератор (константы `1103515245` и `12345`, 30 бит из двух порций по 15):
для игр и опытов, не для защиты. Одинаковое начало даёт одинаковую последовательность. Для новой в каждом запуске:
`посеять(время())`.

## Ошибки

**Компилятор** называет номер строки и причину по-русски, например
`ошибка: строка 3: переменная «икс» нигде не задана`.

**ВМ** останавливает программу, система продолжает работать. Запуск на ПК показывает `vm error КОД`, шелл ПТ
печатает `vm error N` (код без знака).

| Код | Причина |
|-----|---------|
| -13 | индекс вне списка или строки, недопустимый размер списка |
| -12 | не хватает памяти для вызова функции (слишком глубокая рекурсия) |
| -7 | деление на ноль |
| -6 | нет памяти или неверный адрес |
| -4 | слишком много вложенных вызовов (больше 128) |

Полный список кодов в [BYTECODE.md](BYTECODE.md).

## Отличия от Питона

- Только целые 32 бита, нет дробных чисел.
- `//` и `%` обрезают к нулю.
- `и`, `или` возвращают 0 или 1, а не один из операндов.
- Типы определяются при компиляции; число и строка не смешиваются; строка не может быть условием.
- Нет словарей, кортежей (кроме присваивания нескольких значений), классов, исключений, вложенных функций.
- Списки фиксированной длины; память освобождается метками, а не сборщиком мусора.
- Функции определяются только на верхнем уровне; шаг `диапазон` только константа.

(их должна поймать ВМ). Запуск: `python3 tools/test_slog.py out/host`.

## Планы

Дробные числа, словари, списки с изменяемой длиной, обработка ошибок (`попытка`), форматирование строк, вызовы
файлов и запуска программ, доступ к оборудованию для драйверов, компилятор на самом Слоге (чтобы ПТ собирал
программы сам).
