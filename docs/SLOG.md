# Слог: язык программирования для ПТ

Питоноподобный язык, где **все ключевые слова и имена по-русски**. Латинские буквы в именах
запрещены компилятором. Программа компилируется в байткод ПТ (см. `BYTECODE.md`) и работает
на ПТ, КПТ и роботе.

Файлы с исходным кодом называются `*.sl` (расширение ASCII, потому что UART пока
передаёт только латиницу в именах файлов).

## Сборка и запуск

    python3 tools/slog.py examples/privet.sl out/privet.pta     # Слог -> ассемблер
    python3 tools/ptasm.py out/privet.pta out/privet.ptb        # ассемблер -> байткод
    ./out/host out/privet.ptb                                   # запуск на ПК

Готовый `.ptb` кладётся на дискету B (`tools/mkfs.py`) и запускается в шелле: `run privet.ptb`.

## Пример

    функция факт(н):
        если н <= 1:
            вернуть 1
        вернуть н * факт(н - 1)

    печать("факториал 10 =", факт(10))

## Синтаксис

- Блоки задаются отступом из **пробелов** (табуляция запрещена), после строки с `:`.
- Короткие блоки можно писать в одну строку: `если х > 0: печать(х)`.
- Комментарий начинается с `#`. Длинные вызовы можно переносить внутри скобок.
- Имена: русские буквы, цифры, `_` (`счёт`, `сумма_1`). Нельзя называть переменные словами языка.

### Слова языка

| Слово | Смысл |
|-------|-------|
| `если` `иначе_если` `иначе` | условие |
| `пока` `прервать` `продолжить` | цикл |
| `функция` `вернуть` | функции |
| `глобальная` | изменять глобальную переменную внутри функции |
| `пропуск` | пустая команда (пустых блоков не бывает) |
| `и` `или` `не` | логика (`и`, `или` вычисляются лениво) |
| `истина` `ложь` | 1 и 0 |

### Значения и операции

Есть только **целые числа 32 бита со знаком** (от -2147483648 до 2147483647). Строки существуют
только как аргументы `печать`.

| Операции | Приоритет |
|----------|-----------|
| `или` | низший |
| `и` | |
| `не` | |
| `==` `!=` `<` `<=` `>` `>=` (цепочки `a < b < c` запрещены) | |
| `\|` | |
| `^` | |
| `&` | |
| `<<` `>>` | |
| `+` `-` | |
| `*` `//` `%` | |
| унарные `-` `~` | высший |

Составное присваивание: `+=` `-=` `*=` `//=` `%=`.
Деление `//` и остаток `%` **обрезают к нулю** (в Питоне округляют вниз): `-7 // 2` это `-3`.
Сдвиг `>>` арифметический (знак сохраняется). Переполнение заворачивается.

### Переменные

- Присваивание создаёт переменную: `икс = 5`.
- Переменные верхнего уровня глобальные. Внутри функции присваивание создаёт **локальную**
  переменную, а читать можно и глобальные. Чтобы изменить глобальную, объявите `глобальная имя`.
- Читать переменную, которой нигде нет, нельзя (ошибка компиляции).
- Обязательно задавайте значение до чтения: локальные при входе в функцию равны 0.

### Функции

    функция имя(параметр1, параметр2):
        ...
        вернуть значение

- Определяются только на верхнем уровне, вызывать можно до определения.
- Всегда возвращают число: без `вернуть` (или с пустым `вернуть`) это 0.
- Рекурсия работает. Глубина ограничена 128 вложенными вызовами и памятью программы.

### Встроенные команды и функции

| Имя | Действие |
|-----|----------|
| `печать(a, b, ...)` | вывести значения через пробел и перевод строки (строки и числа). Это команда, внутри выражений её использовать нельзя |
| `символ(код)` | вывести один байт, вернуть 0 |
| `ввод_символ()` | прочитать байт с консоли, -1 если ничего нет |
| `читать(адрес)` `писать(адрес, значение)` | слово (4 байта) в памяти программы |
| `читать_байт(адрес)` `писать_байт(адрес, значение)` | один байт в памяти |
| `свободная_память()` | адрес, с которого память не занята данными программы |

Экранирование в строках: `\н` перевод строки, `\т` табуляция, `\"` кавычка, `\\` обратная косая.

## Ошибки

Компилятор сообщает номер строки и причину по-русски, например
`ошибка: строка 3: переменная «икс» нигде не задана`.
Ошибки выполнения ловит ВМ (деление на ноль, переполнение стека, выход за память):
программа останавливается, система продолжает работать.

## Планы

Строковые переменные, списки, цикл `для`, шестнадцатеричные числа, компилятор на самом Слоге
(чтобы ПТ собирал программы сам).
