# Слог: язык программирования для ПТ

Питоноподобный язык, где **все ключевые слова и имена по-русски**. Латинские буквы в именах
запрещены компилятором. Программа компилируется в байткод ПТ (см. `BYTECODE.md`) и работает
на ПТ, КПТ и роботе.

Файлы с исходным кодом называются `*.sl` (расширение ASCII, потому что UART пока
передаёт только латиницу в именах файлов).

## Сборка и запуск

    python3 tools/slog.py examples/privet.sl out/privet.pta     # Слог -> ассемблер
    python3 tools/ptasm.py out/privet.pta out/privet.ptb        # ассемблер -> байткод
    ./out/host out/privet.ptb                                   # запуск на ПК

Готовый `.ptb` кладётся на дискету B (`tools/mkfs.py`) и запускается в шелле: `run privet.ptb`.

Компилятор состоит из трёх модулей: `slog_lex.py` (буквы и отступы), `slog_parse.py`
(дерево программы), `slog_gen.py` (ассемблер), а `slog.py` их связывает.

## Пример

    функция факт(н):
        если н <= 1:
            вернуть 1
        вернуть н * факт(н - 1)

    печать("факториал 10 =", факт(10))

    данные = [5, 3, 9, 1]
    для х в данные:
        печать(х)

## Синтаксис

- Блоки задаются отступом из **пробелов** (табуляция запрещена), после строки с `:`.
- Короткие блоки можно писать в одну строку: `если х > 0: печать(х)`.
- Комментарий начинается с `#`. Длинные вызовы и списки можно переносить внутри скобок.
- Имена: русские буквы, цифры, `_` (`счёт`, `сумма_1`). Нельзя называть переменные словами языка.

### Слова языка

| Слово | Смысл |
|-------|-------|
| `если` `иначе_если` `иначе` | условие |
| `пока` `прервать` `продолжить` | цикл по условию |
| `для` ... `в` | цикл по числам или по списку (`в` особое слово только в заголовке `для`) |
| `функция` `вернуть` | функции |
| `глобальная` | изменять глобальную переменную внутри функции |
| `пропуск` | пустая команда (пустых блоков не бывает) |
| `и` `или` `не` | логика (`и`, `или` вычисляются лениво) |
| `истина` `ложь` | 1 и 0 |

### Числа

Есть только **целые числа 32 бита со знаком** (от -2147483648 до 2147483647).

| Запись | Пример | Значение |
|--------|--------|----------|
| десятичное | `255` | 255 |
| шестнадцатеричное, префикс `0ш` | `0шЕЕ` | 255 |
| двоичное, префикс `0д` | `0д1010` | 10 |

В шестнадцатеричных числах цифры 10-15 пишутся русскими буквами **А Б В Г Д Е** (любой регистр),
латинские буквы запрещены. Число до 8 цифр, `0шЕЕЕЕЕЕЕЕ` это -1.

Строки существуют только как аргументы `печать`.

### Операции

| Операции | Приоритет |
|----------|-----------|
| `или` | низший |
| `и` | |
| `не` | |
| `==` `!=` `<` `<=` `>` `>=` (цепочки `a < b < c` запрещены) | |
| `\|` | |
| `^` | |
| `&` | |
| `<<` `>>` | |
| `+` `-` | |
| `*` `//` `%` | |
| унарные `-` `~` | |
| индекс `а[и]`, вызов `ф(...)` | высший |

Составное присваивание: `+=` `-=` `*=` `//=` `%=` (и для элементов списка).
Деление `//` и остаток `%` **обрезают к нулю** (в Питоне округляют вниз): `-7 // 2` это `-3`.
Сдвиг `>>` арифметический (знак сохраняется). Переполнение заворачивается.

### Переменные

- Присваивание создаёт переменную: `икс = 5`.
- Переменные верхнего уровня глобальные. Внутри функции присваивание создаёт **локальную**
  переменную, а читать можно и глобальные. Чтобы изменить глобальную, объявите `глобальная имя`.
- Читать переменную, которой нигде нет, нельзя (ошибка компиляции).
- Локальные переменные при входе в функцию равны 0.

### Функции

    функция имя(параметр1, параметр2):
        ...
        вернуть значение

- Определяются только на верхнем уровне, вызывать можно до определения.
- Всегда возвращают число: без `вернуть` (или с пустым `вернуть`) это 0.
- Рекурсия работает. Глубина ограничена 128 вложенными вызовами и памятью программы.

### Списки

    а = [10, 20, 30]        # литерал
    б = список(5)           # пять нулей
    а[1] = 50               # запись; можно и а[1] += 2
    печать(а[0], длина(а))  # чтение и длина
    м = [[1, 2], [3, 4]]    # списки в списках: м[1][0] это 3

- Размер списка **фиксирован** при создании.
- Список это адрес блока памяти, поэтому при передаче в функцию копии не делается:
  функция видит и может менять тот же список.
- Индекс проверяется: выход за границы останавливает программу (ошибка ВМ `-13`).
- Память под списки берётся из кучи и не освобождается до конца программы.

### Циклы

    для к в диапазон(5):            # 0 1 2 3 4
    для к в диапазон(2, 11, 3):     # 2 5 8
    для к в диапазон(5, 0, -2):     # 5 3 1
    для х в [4, 5, 6]:              # по элементам списка
    пока условие:                   # по условию

- Шаг в `диапазон` обязан быть числом-константой (не нулём).
- Изменение переменной цикла внутри тела не влияет на ход цикла.
- `прервать` выходит из цикла, `продолжить` переходит к следующему шагу.

### Встроенные команды и функции

| Имя | Действие |
|-----|----------|
| `печать(a, b, ...)` | вывести значения через пробел и перевод строки (строки и числа). Это команда, внутри выражений её использовать нельзя |
| `символ(код)` | вывести один байт, вернуть 0 |
| `ввод_символ()` | прочитать байт с консоли, -1 если ничего нет |
| `список(n)` | новый список из n нулей |
| `длина(список)` | число элементов |
| `выделить(байты)` | выделить обнулённую память из кучи, вернуть адрес |
| `читать(адрес)` `писать(адрес, значение)` | слово (4 байта) в памяти программы |
| `читать_байт(адрес)` `писать_байт(адрес, значение)` | один байт в памяти |

Экранирование в строках: `\н` перевод строки, `\т` табуляция, `\"` кавычка, `\\` обратная косая.

## Ошибки

Компилятор сообщает номер строки и причину по-русски, например
`ошибка: строка 3: переменная «икс» нигде не задана`.
Ошибки выполнения ловит ВМ: программа останавливается, система продолжает работать.

| Код ВМ | Причина |
|--------|---------|
| -13 | индекс вне списка или недопустимый размер списка |
| -12 | не хватает памяти для вызова функции (слишком глубокая рекурсия) |
| -7 | деление на ноль |
| -6 | нет памяти или неверный адрес |
| -4 | слишком глубокая рекурсия (больше 128 вызовов) |

## Планы

Строковые переменные, списки с изменяемой длиной, компилятор на самом Слоге
(чтобы ПТ собирал программы сам).
