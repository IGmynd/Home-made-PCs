# Файловая система PTFS (v1)

Простая **плоская** файловая система для носителей данных (класс 2, см. [MEDIA.md](MEDIA.md)). Сейчас **только
чтение**, запись и расширение каталога в планах. Сборка образа: `tools/mkfs.py`, чтение: `kernel/ptfs.c`.

## Принципы

- Без папок: один каталог на носитель.
- Файлы лежат подряд, каждый начинается с границы сектора (512 байт). Нет фрагментации.
- Каждый файл защищён CRC32. Ядро проверяет его при каждом чтении и не запускает повреждённое.
- Читается за несколько десятков строк кода: файловая система должна быть понятна целиком.

## Раскладка образа

Номера секторов считаются от начала области образа (в носителе это сектор 1, после заголовка).

| Сектор | Содержимое |
|--------|------------|
| 0 | каталог |
| 1... | файлы подряд, каждый выровнен по сектору |

### Каталог (сектор 0)

| Смещение | Размер | Поле |
|----------|--------|------|
| 0 | 4 | magic `PTFS` |
| 4 | 2 | версия (1) |
| 6 | 2 | число файлов (до 15) |
| 8 | 24 | резерв |
| 32 + 32·i | 32 | запись файла i |

### Запись файла (32 байта)

| Смещение | Размер | Поле |
|----------|--------|------|
| 0 | 16 | имя: ASCII, до 15 символов, добивается нулями |
| 16 | 4 | первый сектор файла (от начала образа, не меньше 1) |
| 20 | 4 | размер в байтах |
| 24 | 4 | CRC32 содержимого (по ровно `размер` байтам) |
| 28 | 1 | тип |
| 29 | 3 | резерв |

Типы файлов: `0` данные, `1` байткод (`.ptb`), `2` текст (`.txt`). `mkfs.py` определяет тип по расширению.

Имена только латиницей: консоль ПТ пока передаёт только ASCII в именах. Содержимое файлов может быть любым
(текст в UTF-8).

## Как ядро читает файл

1. `ptfs_mount`: читает заголовок носителя, проверяет magic `PTMD` и его CRC, берёт начало и длину образа,
   читает каталог, проверяет magic `PTFS`, версию и число файлов.
2. `ptfs_find`/`ptfs_get`: поиск и перебор записей каталога.
3. `ptfs_read`: проверяет, что файл помещается в буфер, лежит внутри образа и (по границам) не выходит за носитель,
   читает сектора и сверяет CRC32 с каталогом.

### Коды ошибок

| Код | Значение |
|-----|----------|
| -1 | нет носителя или не наш заголовок |
| -2 | заголовок носителя повреждён (CRC) |
| -3 | в носителе нет образа |
| -4 | нет файловой системы PTFS |
| -5 | некорректный каталог (больше 15 файлов) |
| -6 | файла нет |
| -7 | файл не влезает в буфер или выходит за носитель |
| -8 | содержимое файла повреждено (CRC не совпала) |

Шелл печатает коды без знака: `no disk B, error 1`, `read error 8`.

## Создание образа

```
python3 tools/mkfs.py out/fs.img out/hello.ptb out/privet.ptb examples/readme.txt
python3 tools/mkmedia.py out/floppyB.img --kernel out/fs.img --label PT-USER --cls 2
```

## Ограничения и планы

- Не больше 15 файлов (каталог занимает один сектор). Планируется каталог из нескольких секторов.
- Только чтение. Запись (создание, замена, удаление, рост образа с обновлением заголовка) в планах: профиль-дискета
  обязана быть записываемой.
- Размер файла в ядре ограничен буфером программы (сейчас 4 КБ).
